# Biomarker Data Analysis – THR-6E Biomarker

## Project Status
✅ Compeleted.

## Objective
To evaluate the prognostic performance of the THR-6E biomarker gene signature in ER+/HER2− breast cancer patients and assess whether the biomarker demonstrates prognostic value beyond random gene signatures.

## Data
Gene expression data from the METABRIC dataset
Clinical data
Published breast cancer gene signatures

## Methods
Data preprocessing and cohort filtering
Survival analysis using KM estimation and log rank test
Comparison with 48 published prognostic signatures
Random gene signature benchmarking
Stepwise gene replacement in THR-6E biomarker
Reduced THR-6E biomarker gene combination analysis

## Tools
- R

## Key Findings
The THR-6E biomarker showed a statistically significant association with ER+/HER2− breast cancer patient Recurrence-Free Survival (RFS).
However, randomly generated gene signatures, modified signatures, and single-gene replacement variants were also able to achieve comparable prognostic performance.
These results suggest that the prognostic signal is not unique to the THR-6E gene set.
The findings indicate that many gene combinations can produce similar survival associations in ER+/HER2− cohorts.
Therefore, while THR-6E remains statistically predictive, the analysis does not support strong biological specificity or mechanistic utility for the signature.
